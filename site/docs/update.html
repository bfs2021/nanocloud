Update and remove

Nano Cloud tells you when a release is out. Installing it is one command.

Update

sudo nanocloud update

This downloads the release, checks its signature and checksum, swaps the binary and restarts the service. The previous binary is kept as nanocloud.prev and put back if the new daemon doesn't come up reporting the new version.

--checkJust say whether there's a newer release
--version vX.Y.ZInstall a specific release

VMs keep running during an update. The daemon checks for a release at most every 12 hours and shows it in the sidebar and in Settings → Updates, where you can turn the check off. It never installs anything by itself.

Remove, keeping your VMs

sudo nanocloud uninstall

This removes the binary, the service and the configuration. VM disks, the images they're built on, their definitions and the login stay, and it prints what it left and where. Install again and everything is back. On a Mac the image cache goes too, since each VM there has its own full copy of its disk.

Remove everything

sudo nanocloud uninstall --purge

This also stops and deletes every VM Nano Cloud made, their disks, the state directory, the login and the certificate. It can't be undone, so it asks you to type a confirmation (--yes skips it). VLAN links it made stay until the host restarts; they hold no address and nothing is saved for them.

Through the installer script: curl -fsSL …/install.sh | sudo sh -s -- uninstall --purge.
